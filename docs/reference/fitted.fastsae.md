# Extract fitted values (EBLUP or EBP) from a fastsae object

Extract fitted values (EBLUP or EBP) from a fastsae object

## Usage

``` r
# S3 method for class 'fastsae'
fitted(object, ...)
```

## Arguments

- object:

  An object of class `fastsae`.

- ...:

  Additional arguments.

## Value

Vector of fitted estimates.
