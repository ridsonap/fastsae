Understanding the Results

Execution Time: The chart shows median execution time across different dataset sizes. fastsae maintains sub-second performance up to n=250 areas, while sae package already takes over a minute at n=250. At n=1,000, fastsae completes in ~58 seconds versus ~30 minutes for sae.

Memory Efficiency: fastsae uses approximately 1 MB of memory even at n=1,000, while sae requires ~32 GB. This 36,000× memory reduction enables fastsae to run on resource-constrained environments.

Speedup Factor: The speedup ranges from 3.2× at n=30 to 31× at n=1,000. The increasing advantage at larger scales makes fastsae essential for production workloads with large datasets.
